A tiny entry for [u-puan-one-letter-for-your-day-e54e9c36](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)
on make.fun: a program that writes exactly one letter — `I`, standing
for insomnia, a day counted in ceiling tiles instead of hours — into
`/output/entry.txt`, and nothing else.

Run it with Node 22 and no network:

```sh
node main.ts
```

The letter it writes is the whole entry: one character, no newline,
no punctuation. Behind it sits the word for the day — insomnia — the
honest report of a day carried on no sleep at all.
